## Text, links and quotes

You can write **bold**, *italic* and `inline code`. Links look like [this one](https://github.com). Quotes work too:

> Write down what you learned while it is still fresh.

## Code

```bash
nmap -sC -sV -oN scan.txt 10.10.10.10
```

## Images

Put the file in `assets/images/`, then reference it like this:

```markdown
![Short description](/assets/images/screenshot.png)
```

## Video

Paste a YouTube embed inside a `video` div so it stays responsive:

```html
<div class="video"><iframe src="https://www.youtube.com/embed/VIDEO_ID" allowfullscreen></iframe></div>
```
